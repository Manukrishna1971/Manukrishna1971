## 🎯 Engineering Focus

- 👁️ **Computer Vision & Spatial Intelligence**: Developing real-time object tracking (NMS), biometric verification gates, and dynamic gesture recognition engines running at true 60 FPS in-browser.
- ⚡ **Offline-First & Local LLMs**: Engineering local private AI agents with **CUDA** acceleration, hardware telemetry, and automated system function calling.
- ⚙️ **Systems & Compiler Design**: Building lexical analyzers, LALR(1) grammars, and Abstract Syntax Trees (ASTs) with **Flex, Bison, and C**.
- 🚀 **Cloud & Microservice Infrastructure**: Designing asynchronous **FastAPI** / **Flask** architectures containerized with **Docker** and deployed on **Vercel** and **Render**.
